# Как проверить без других людей

## Автотесты

```bash
cargo test
```

| Тест | Что проверяет |
|---|---|
| `tests/two_nodes.rs` | две ноды обмениваются сообщением |
| `tests/voice_transport.rs` | голосовые кадры доходят по сети |
| `tests/global_rendezvous.rs` | две ноды без адресов и кодов находят друг друга через локальную DHT BitTorrent (~15 с) |
| `i18n` | каждая строка интерфейса переведена на 8 языков |
| `theme` | контраст текста во всех темах ≥ WCAG |
| `voice` | ресемплер 44.1→48 кГц сохраняет длительность и тон |
| `music`, `voice_rec` | декодирование WAV/mp3/flac, WAV голосовых |

## Несколько нод на одном компьютере

```bash
scripts/peers.sh 5            # 5 консольных нод
./target/release/cybercord --name Я   # окно найдёт их через mDNS
```

Команды консольного режима:

| Команда | Что делает |
|---|---|
| `/find кар` | найти людей по имени |
| `/nodes` | ноды, которые знает эта нода (карта в тексте) |
| `/code` | свой код подключения |
| `/addfriend Имя <код>` | добавить друга |
| `/dm Имя текст` | написать в личку |
| `/send файл.gif` / `/send трек.mp3` | отправить файл |
| `/circle 3` | видео-кружок на 3 с (`CYBERCORD_TEST_CAMERA=1` без камеры) |
| `/voicemsg 5` | голосовое на 5 с |
| `/voice sce/lounge`, `/leave` | голосовой канал |
| `/play`, `/stop` | слушать последний трек в канале |
| `/devices` | микрофоны и колонки |
| `/net` | состояние сети |
